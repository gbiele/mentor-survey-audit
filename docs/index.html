📖 Understanding Audit Statuses & Harmonization Flags

🟡
Incomplete / Inferred Options The canonical response options were not fully pre-enumerated in the master English specification, but rather inferred from observed sample responses or parallel scale patterns. Harmonization Risk: Unobserved answer branches (e.g., categories not selected by any respondent in the sample) risk being omitted from the canonical data model.
🔴
Missing Options The variable is present in the national survey export, but has 0 defined response options in the master specification (e.g. conditional branching follow-up questions). Harmonization Risk: Cannot be automatically harmonized until response categories and value codes are explicitly added to the master dictionary.
⚠️
Flagged Issues = Incomplete (🟡) + Missing Options (🔴) This metric represents the total sum of all problematic variables requiring review by survey programmers and field teams. These items need explicit option specification, translation verification, or scale completion before freezing data for cross-country joint analysis.
🟢
Fully Identified All canonical response categories are fully defined in the master specification and match the observed survey values with confirmed numerical coding.
⚪
Open-Ended / Continuous Free-text fields, continuous dates/years, numerical intervals (e.g., MacArthur ladder), or matrix header titles where discrete categorical options do not apply.
