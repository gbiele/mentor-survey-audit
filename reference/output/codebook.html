JA-MENTOR codebook

This is the codebook for the youth mental health questionnaire used in the JA-MENTOR project. For every question it shows the wording, the allowed answers, and the numbers used to store those answers in a data file.

This page lists 63 questions (229 items). Generated 2026-08-18.

What a codebook is for

Survey software stores answers as text (“Girl”, “Sometimes”). Analysis software needs numbers. A codebook records the mapping: which question is which column, and which answer becomes which number.

Use the yellow name in analysis. The grey “original” name is what the German survey software (EUSurvey) called that column in the export.

Two versions of the questionnaire

The JA-MENTOR youth questionnaire exists in more than one draft. This codebook combines:

  • FHI English — the English questionnaire (21 questions only in this version).
  • German test — a version run in EUSurvey, with a small set of test answers (14 questions only in this version).

28 questions appear in both. They are not identical overall. Each card is tagged so you can see which version a question comes from.

How to read a yellow name

Each analysis name is a short nickname for the scale, then a number for the item on that scale. Example: bcfpi_mood3 is item 3 of the BCFPI mood questions. Names are usually at most 8 letters plus that number. If a scale has 10 or more items, the number has a leading zero (cats01).

Mental health items come from the youth version of the Brief Child and Family Phone Interview (BCFPI), a standard questionnaire about feelings and behaviour. Those names start with bcfpi_.

How answers become numbers

  • Ordered answers (Never, Sometimes, Often) are numbered 0, 1, 2, … so that the “lowest” end of the scale is 0. For how often questions, Never is always 0, even if the questionnaire listed Always first.
  • Named categories with no natural order (country, gender) are numbered 1, 2, 3, …
  • True numbers (year of birth, age, a 1–10 ladder) are stored as entered.
  • Typed comments stay as text, not a number.

How complete the answer list is. Green means the full list was recovered. Amber or red means the German test file did not contain every option. 9 questions are tagged that way.

How answers are numbered. Ordinal = ordered categories. Nominal = named categories with no order. Interval = a real number. Free text = written words.
